# @opensesame/connector-bridge

The wire protocol, the request policy and the host table shared by the Pages
app and the [connector bridge extension](../../apps/browser-extension-bridge)
([ADR 0199](../../docs/adr/0199-connector-bridge-extension.md)). Plain data and
pure functions; no `browser.*`, no DOM, no React, so both sides run the same
code and the same tests.

| File | What it is |
|---|---|
| `src/protocol.ts` | The three operations (`hello`, `need`, `fetch`), their envelopes, the bounds, and a strict parser for each direction. An unknown key, a wrong type or an oversize value is not a request. |
| `src/policy.ts` | `checkFetch`: HTTPS only, a host the table names *for the provider named*, one a person allowed, a closed method set, headers a browser would let a page set, a bounded body. `responseHeaders` drops cookies. A request that is not exactly right is refused, never repaired. |
| `src/table.generated.ts` | Each provider the browser cannot reach by itself and the exact hosts the bridge may send its requests to. Generated by `scripts/emit-table.mjs` from `spec/connectors/browser-policy.json`, the catalog's egress and each provider's key-check host; a freshness test fails when it drifts (`pnpm --filter @opensesame/connector-bridge generate:table`). |

```bash
pnpm --filter @opensesame/connector-bridge test
pnpm --filter @opensesame/connector-bridge typecheck
```
