Option B · One scrolling checklist

Why

The vocabulary the app already speaks — the connectivity bar's ceremonies are rows that expand in place and never navigate. Everything optional is visibly optional, and a returning operator opens the one row they came for.

Costs

On a phone an expanded row pushes the finish button off screen, so the one action that ends setup moves every time something opens — which is the complaint that started this. Nothing states an order, so "am I done?" has no answer.
