Why

The ceremony is one screen and one question, and this is not a second one: it asks nothing, has no wrong answer, and does not gate the commit. So it takes the shape the screen already uses for its other sections — a heading in the same voice as "Add a provider", below the question rather than in front of it. And it obeys the rule the ceremony lives by: the whole section is withheld where the browser will not install, the way Unlock is withheld where there is no sealed vault.

Costs

The one-question screen now carries something that is not the question. It is bounded — absent entirely on a browser that cannot install, and never in front of the sign-in list — but it is one more thing on the only screen the ceremony has, and the next such offer will point at this one as precedent.
