It needs to see the page, so it has to be a vision model.

What it is shown, and what it is not.

It sees the page with every password field stripped and every credential box masked — struck out before the picture exists, not before it is displayed. It says which field to fill and never what to type: there is no tool that hands it a value.

Skip this and this device's own model does it, where the browser has one that can see a page. Where it has not, password changes stay as they are today: OpenSesame takes you to the right settings page and you do it yourself. It never half-tries, and skipping never starts a download.
