What the model provider becomes a party to

Configuring a model is not a preference like a theme. Whoever runs it watches a browser work a password-reset form. This is the line the setup step is asking the operator to agree to, so the step states it in one sentence and this is the long form behind it — ADR 0076 §1.

Crosses to the model

  • the page, with every input[type=password] value stripped
  • a screenshot with credential boxes masked
  • the site's own change-password URL
  • which step of the ladder this is
  • an outcome: filled, submitted, refused

Never crosses, at any step

  • the old password, or the new one
  • the candidate the generator made
  • anything else in the vault
  • a key, a wrapper, or a session bearer
  • the account's other credentials

Why the right column holds

The tool does not exist

The model calls fill_credential(ref, selector) — it names which credential and where, and a deterministic controller types the value. There is no read_field_value and no get_secret, in the same sense that the connector world has no secrets.get. Nothing has to deny a call that cannot be made.

Redaction is at capture

Password values are stripped before the DOM is serialized; credential boxes are masked in the capture pipeline before an image exists. Redaction applied when a transcript is displayed is not redaction — the unredacted form was already written down somewhere.

The generator returns a handle

generate_candidate(policy) hands back a reference, not a password. So the new credential is never a string the model has held, even for the moment between making it and typing it.

The browser plane is the narrowest row, loopback included — which is why declining to name a provider resolves to it rather than to nothing. ADR 0083.

The residual risk the setup step should not pretend away.

A redacted page is still your page: which site, which account name, that you are changing a password today. A hosted provider learns that much, and the browser and local options exist so an operator who will not accept it has somewhere to go. That is why the step leads with the device you are holding rather than the biggest model.

And the left column does not shrink because the model ran in-page. The frames go into the sealed observation log either way, so redaction stays at capture on every plane — where the model ran changes who watches, never what there is to watch.
