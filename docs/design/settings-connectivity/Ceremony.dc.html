Why this shape

It opens working

The old panel opens with an empty url input and waits. This one starts probing the moment it opens, because it already knows the three places a daemon can be. The fastest ceremony is the one you never interact with.

One primary action

Today's panel offers Connect Tailscale, Use this URL and Show QR side by side, and you cannot tell which one is for you. Here the discovered path is the button; the other two are alternatives you reach only when discovery fails.

The field is the fallback

Typing a tailnet FQDN by hand is the least likely path and the easiest to get wrong, so it lives on the failure screen — with the clipboard and the shipped loopback default offered as fills.

It says what it wrote

Pairing quietly sets three endpoints today. Showing them at the end is what makes the Endpoints panel safe to collapse — you have already seen the values, so you do not go looking for them.
